Canine EEG, checked before it is claimed.

This project asks a practical question: before a model result is turned into a neuroscience story, can we prove the data, labels, quality checks, and validation design are strong enough to carry that story?

A validation-first framework for canine EEG

The work does not chase the highest classifier score. It builds a careful path from raw Neuroscan CNT files to dog-level statistical evidence, so the final claim is honest, reproducible, and useful.

The most interesting result here is not that the classifier wins. It is that the framework knows when the classifier has not earned a biological interpretation yet.

That may sound modest, but in EEG it matters. A dataset can contain thousands of epochs while still having only a small number of independent biological subjects. If a model learns dog identity, recording drift, baseline amplitude, or an uncertain label map, the score can look meaningful while the science remains fragile.

This project turns those weak points into explicit checks. The positive story is a stronger research habit: validate the pipeline first, then decide what claims the evidence is allowed to support.

The short version

What this work found

The raw EEG import path can be validated. Event integrity can be audited. Human EEG quality-control assumptions can be exposed before they quietly reject every canine recording. Dog identity, session position, and baseline persistence can be measured as possible shortcuts. And condition decoding, when evaluated by leaving out entire dogs, stays near the within-dog shuffled-label null.

The conclusion is intentionally bounded: the current evidence package is auditable, but not ready for stronger condition-level neuroscience claims. That is still a useful result. It tells the next dataset, next adapter, and next experiment exactly what must be made clearer.

Why it matters

A classifier score is not automatically a scientific claim

EEG data are rich, but they are also easy to fool. Many trials from the same animal are not the same as many animals. If train and test folds share the same dog, a model may learn the dog rather than the experimental condition.

That is why this framework uses the dog as the unit of inference. The model is asked a harder and more honest question: can the pattern generalize to an unseen dog?

The goal is not to make the model look impressive. The goal is to make the evidence difficult to misunderstand.

This is the part I like most about the project. It treats "almost, but not yet" as a publishable kind of knowledge. In computational neuroscience, knowing where a claim stops is part of doing the science properly.

Evidence ledger

The main checks, in plain language

Layer What was checked What it means Status
Raw decoding 32-bit CNT sample structure, checksums, header scaling, and MNE/header agreement. The corrected import path is supported before downstream analysis begins. Supported
Events Expected trigger codes, event counts, repetitions, and run-integrity deviations. Recording-level issues become visible instead of being hidden inside pooled epochs. Caution
Labels Trigger-code-to-condition provenance and missing original codebook, task script, and trial logs. Candidate condition labels can be used for pipeline checks, but not treated as verified neuroscience truth. Blocked

What is interesting

The positive result is a cleaner research standard

  • Raw data validation becomes part of the method. The framework documents why the corrected CNT import path is used, instead of assuming the first loader was trustworthy.
  • Warnings are preserved. PASS, WARN, and FAIL states remain visible, which is exactly what a reviewer needs when the dataset is small and heterogeneous.
  • Dog-level inference is enforced. The project keeps the biological unit honest: 2,820 epochs do not become 2,820 independent dogs.
  • Confounds are treated as scientific evidence. Dog identity, session drift, and baseline persistence are not annoyances; they are part of understanding the dataset.
  • Reproducibility becomes evidence. Checksums, configuration, software versions, random seed, report outputs, and clean-release status become part of what the paper can claim.
  • The result is reusable. The long-term shape is a dataset-adapter framework, where each new canine EEG dataset brings its own specification, event design, and mapping provenance.

Final take

A careful no is still progress

This project does not say canine EEG has no useful signal. It says the current evidence, under the current candidate labels and dog-level validation, should not be stretched into a stronger claim than it can support.

That is a good outcome for a methods paper. It gives future work a better checklist: recover or verify the condition codebook, keep dogs separated during evaluation, report QC provenance, preserve warnings, and make reproducibility metadata part of the result.

Safe Claim

A reproducible framework can audit canine EEG decoding, event validity, QC provenance, confounds, and dog-level statistical evidence before biological claims are made.

Not Claimed

  • No state-of-the-art decoding claim.
  • No clinical diagnosis claim.
  • No generalized canine cognition claim.
  • No olfactory or cancer-detection claim.
  • No universal canine EEG QC standard.
  • No proof that canine EEG lacks condition information.

Best Next Steps

  • Recover the original stimulus codebook or trial log.
  • Resolve event and QC findings before stronger claims.
  • Regenerate final reports from a clean release.
  • Add a second real dataset adapter.
