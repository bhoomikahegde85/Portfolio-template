Research case study

A validation-first pipeline for canine EEG.

A classifier can produce a number before the science is ready. This project builds the checks that decide what a canine EEG result can responsibly claim.

The framework audits raw Neuroscan CNT recordings, event integrity, condition-label provenance, canine-specific quality control, confounds, dog-level decoding, empirical nulls, and reproducibility metadata. The goal is not to maximize classification accuracy. The goal is to make every scientific claim traceable to the evidence that supports it.

Fig. 1 Validation path. Raw signal integrity, event structure, label provenance, QC, confounds, and statistics are checked before interpretation.

1. Why this problem matters

EEG machine learning can look larger than it is. A study may contain thousands of epochs, but those epochs can come from a small number of biological subjects. In this case, the downstream analyses use 2,820 epochs from 16 dogs. The dog is the biological unit; the epochs are repeated observations nested inside each dog.

That distinction changes the whole analysis. A model that sees epochs from the same dog during training and testing may learn dog identity, recording context, session order, baseline amplitude, or preprocessing artifacts. The scientific question is therefore not simply whether a classifier can predict a label. The question is whether the prediction survives the validation checks needed for a biological claim.

Research unit

The dog is the independent biological unit. Epochs are useful observations, not independent animals.

Model role

Decoding is treated as a validation endpoint, not as an accuracy competition or deep-learning contribution.

Claim style

Every result is tied to what it supports, what it constrains, and what remains unresolved.

2. The scientific claims

The project makes methodological claims. These claims are positive, but deliberately specific: they describe what the framework can verify, expose, or constrain in the current canine EEG evidence package.

Claim 1

Raw CNT decoding can be audited and corrected.

The low-level decoding audit identified a concrete import-width failure: 32-bit CNT samples had previously been interpreted as split 16-bit words. The corrected audit supports 32-bit decoding across 17 raw recordings, with official checksum agreement and maximum MNE/header scaling error of 2.91e-11 uV.

Claim 2

Event-code integrity and condition-label validity are different questions.

Numeric trigger codes can be counted, ordered, and checked against expected repetitions without assuming that every code-to-condition mapping is experimentally verified. This separation prevents candidate labels from being promoted into condition-level neuroscience claims.

Claim 3

Canine EEG quality control needs provenance.

The QC layer records recording-level and epoch-level metrics while preserving whether thresholds are exploratory or externally justified. This matters because human-style EEG thresholds can behave poorly on canine recordings; the framework turns that risk into visible evidence.

Claim 4

Dog identity, session position, and baseline persistence are measurable confounds.

The framework reports dog-identity structure in raw embeddings, session-position associations, and baseline-to-response persistence. These findings do not assign a biological cause. They show which structure must be considered before interpreting condition decoding.

Claim 5

Leave-one-dog-out decoding remains close to a dog-preserving null.

Under candidate condition labels, leave-one-dog-out macro AUC is approximately 0.503 and does not exceed the within-dog shuffled-label null reference. This is a useful result: it protects the paper from overstating condition decoding while preserving a clear validation baseline for future work.

Claim 6

Reproducibility is part of the evidence.

The validation run records raw checksums, configuration hash, software versions, random seed, exact command, and generated report checksums. The result is not just a narrative summary; it is an auditable evidence package.

3. Dataset and provenance

The case study uses a public canine EEG dataset associated with auditory word processing. The raw data are represented as 17 numeric Neuroscan CNT recordings, each expected to contain eight channels sampled at 1000 Hz. The expected event design contains trigger codes 1-48, five repetitions per code, and 240 stimulus events per complete recording.

The downstream analysis cohort contains 16 dogs and 2,820 epochs. Dog 40 is documented as excluded from downstream analyses because of quality-control and event-integrity concerns. The page leaves the dataset link below as a placeholder so the final DOI or archive URL can be inserted cleanly.

4. Methodology

The method is organized as a validation chain. Each stage receives explicit inputs, performs a defined audit, writes machine-readable and human-readable outputs, and constrains the claims that can follow.

Fig. 2 Methodological structure. The framework converts validation checks into claim permissions.
  • Raw import: Decode CNT files as signed little-endian 32-bit samples and verify scaling.
  • Event audit: Check trigger range, repetitions, missing or extra events, ordering, and run constraints.
  • QC provenance: Compute recording and epoch metrics while keeping threshold status explicit.
  • Confound analysis: Measure dog identity, session position, and baseline-persistence structure.
  • Statistics: Use leave-one-dog-out evaluation, within-dog permutation nulls, and dog-level bootstrap summaries.

5. Results

The main result is a validated evidence boundary. The corrected CNT import path is supported. Recording-level event deviations are visible. QC provenance is explicit. Confounds are measured. Dog-level decoding is near null under the current candidate labels.

Result Evidence Interpretation
CNT decoding 17/17 files show corrected 32-bit consistency and checksum agreement. The raw signal path is reproducible and auditable.
Event integrity 9 recordings match the exact event design; 8 require event review. Event quality is recording-specific and should not be hidden by pooling.
Condition mapping The original trigger-code-to-stimulus codebook was not recovered locally. Condition labels remain candidate labels for validation analyses.
Dog-level decoding Macro AUC is about 0.503 and remains below the within-dog null reference. The current evidence supports a careful null decoding result, not a broad cognition claim.
Reproducibility Checksums, config hash, software versions, command, seed, and report outputs are recorded. The analysis is packaged as an auditable research object.
The important point is not that the classifier is weak. The important point is that the framework can tell when a classifier result should remain a validation result rather than becoming a biological claim.

6. How to read the null decoding result

A near-null decoding result is not the same as proving there is no neural information. It means that under the current candidate labels, current feature set, fixed lightweight models, and leave-one-dog-out evaluation, condition decoding does not exceed a dog-preserving shuffled-label reference.

That is still scientifically useful. It prevents a model score from being stretched into semantic decoding, canine cognition, clinical interpretation, or population-level generalization. It also gives the next study a concrete checklist: verified condition mapping, stronger dog-level cohorts, transparent QC, and the same subject-independent evaluation discipline.

7. What makes the framework reusable

The reusable part is the validation structure. New datasets can provide their own dataset specification, event design, stimulus mapping, adapter, QC provenance, and report outputs. The same logic can then ask: what does this dataset support, what needs a caveat, and what should remain a future claim?

That makes the project a neuroinformatics contribution rather than a one-off classifier. It is designed to make small canine EEG studies easier to inspect, reproduce, compare, and improve.
